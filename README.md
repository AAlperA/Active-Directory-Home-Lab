# Active Directory Home Lab

## Project Overview

This project is a hands-on Windows Server lab built using VMware Workstation Pro.

The objective is to simulate a small corporate network and practice
Windows Server administration.

## Lab Environment

- Domain Controller: DC01
- Client Machine: CLIENT01
- Server OS: Windows Server 2022
- Client OS: Windows 11 Pro
- Virtualization: VMware Workstation Pro
- Network: VMware NAT

## Technologies

- Active Directory Domain Services (AD DS)
- DNS
- DHCP
- Group Policy (GPO)
- Wireshark
